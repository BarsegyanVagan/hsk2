# HSK 2 · 汉字

Офлайн-приложение (PWA) для слов HSK 2 из учебника 新HSK教程 2: 207 слов и 3 имени собственных, уроки 1–15.
Всё хранится на устройстве, сервер и регистрация не нужны.

## Что умеет

- **Режимы:** карточки с самопроверкой, 4 варианта ответа, тоны, «Найди пару», блиц на 60 секунд.
- **Направления:** 汉字 → перевод, перевод → 汉字, пиньинь → 汉字, на слух (голосом устройства).
- **Интервальное повторение:** кнопка «Повторить сегодня», трудные слова, избранное ⭐, свой набор уроков и слов.
- **Карточки:** свайпы, отмена ответа, подсказка, пример предложения, ввод пиньиня (включается в настройках).
- **Словарь:** поиск по иероглифам, пиньиню (можно без тонов) и переводу; страница слова с анимацией порядка черт и письмом пальцем.
- **Прогресс:** серия дней, цель на день, календарь занятий, график, достижения, история.
- **Настройки:** тема, цвет, размер иероглифов, звук и озвучка, экспорт и импорт прогресса.

## Как обновить слова

1. Отредактируйте `hsk_2_1_15.txt`. Формат:
   ```
   УРОК 16
   汉字          hànzì           иероглиф
     > 我在学汉字。 | Wǒ zài xué Hànzì. | Я учу иероглифы.
   ```
   - `★` перед иероглифами — слово сверх программы;
   - `@` — имя собственное;
   - строка `>` — пример к слову выше (необязательно).
2. Дважды щёлкните `update-words.cmd` (Windows). Он пересоберёт `data/words.json`,
   покажет число слов по урокам и скачает данные о порядке черт для новых иероглифов.
3. Загрузите `data/words.json` и `data/strokes.json` на GitHub (папка `data` → Add file → Upload files).
   При изменении кода приложения увеличьте `VERSION` в `sw.js`.

## Файлы

```
index.html, css/styles.css   оболочка и стили
js/app.js                    запуск и общие обработчики
js/core.js                   переходы между экранами, сообщения, окно подтверждения
js/store.js                  данные на устройстве (настройки, повторения, история…)
js/data.js, js/pinyin.js     слова, наборы, поиск; разбор пиньиня
js/session.js                запуск и итог тренировок
js/screens/*.js              экраны
js/vendor/                   Hanzi Writer (MIT) и лицензия данных черт (Arphic)
data/words.json              слова (из hsk_2_1_15.txt)
data/strokes.json            порядок черт (Make Me a Hanzi)
sw.js, manifest.webmanifest  офлайн-режим и установка
scripts/                     конвертер, загрузка черт, иконки
```
